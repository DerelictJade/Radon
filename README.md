# Radon ✨
Introducing **Radon**, a [MelonLoader](https://github.com/LavaGang/MelonLoader) mod for **Neon White** and your best friend for level practice or route testing. Radon allows you to create and load savestates in levels for more sectioned practice or just to try out a new idea.

The main reason I made Radon was because I got frustrated with having to close the game and navigate my mods folder every time I wanted to test something with savestates. With that in mind, Radon is **completely toggleable within game**.

While Radon is enabled you'll have all the usual functions of Xenon (at least those currently implemented), along with some QoL extra improvements. When it's disabled, anticheat gets disabled as well and you're free to grind for PBs as usual!

## Current Features:
* **Can be completely enabled/disabled from settings menu**
* **Savestates** - Record your position, camera angle, and card count to load it back INSTANTLY
    * Optionally resets level timer on load
    * Optionally remember ammo count
* **Phantom Visualizer** - Allows you to see bullets after they hit a wall until they disappear to see phantom timing
* **Bullet scaling** - Change the size of bullet hitboxes. It's SBB time 🔥

## Features to come soon:

## Installation and Usage
* Install [MelonLoader](https://github.com/LavaGang/MelonLoader/releases/tag/v0.6.1) and add to your Neon White installation. Make sure you use v0.6.1.
* **This mod depends on [NeonLite](https://github.com/Faustas156/NeonLite/releases/latest)**, please make sure you have the latest version installed by following the NeonLite installation instructions.
* Download [the latest release](https://github.com/DerelictJade/Radon/releases/latest) and add the `Radon.dll` file to your mods folder.
* If everything is right you should now see "Radon" in your settings menu when you press F5 in-game. Happy practicing!
